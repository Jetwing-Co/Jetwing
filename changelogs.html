Changelogs

Every update to Jetsidian, newest first. We ship changes pretty often, so check back.

v2.4.0 Aug 10, 2026 LATEST

Builder Mode and a big docs pass.

Added
  • Builder Mode in the docs, so you can write and test Jetsidian scripts right in your browser.
  • A proper scripting API reference with events, all the namespaces, data models and packets.
  • Cloud tab in the theme browser for sharing themes with the community.
Fixed
  • Camera freezing for a split second when Silent Aim swapped rotations.
  • Stuck sneak when you opened a GUI while BridgeAssist was running.
Improved
  • KillAura target switching feels a lot smoother now.
v2.3.0 Jul 2, 2026

Clutch update and more Grim work.

Added
  • ClutchV3 with an Auto Clutch mode that predicts your fall the way Grim expects.
  • New Grim bypass profiles for a few movement modules.
Fixed
  • FastPlace CPS not matching the slider value.
  • A couple of modules silently doing nothing after a reload.
Changed
  • Panel still opens with Right Shift, but you can now rebind it per profile.
v2.2.0 May 18, 2026

Visual overhaul.

Added
  • RefineVisuals V2: rounded ESP boxes, gradient glow, pill nametags with a HP bar, chams rim lighting and fading tracers.
Improved
  • Cleaner glass style across the HUD and panel.
  • Better performance when a lot of players are on screen.
v2.1.0 Apr 5, 2026

Scripting and accounts.

Added
  • The scripting system: drop a .java file in the scripts folder and it becomes a toggleable module.
  • HWID lock and a 60 day remember-me login so you dont have to sign in every time.
Fixed
  • Injector needing admin on some systems without telling you why.
v2.0.0 Feb 20, 2026

The big rewrite.

Added
  • 129 modules across every category, all in one client.
  • Injectable into Lunar Client and vanilla Minecraft.
  • Anticheat bypass built from scratch for Watchdog, Grim and NCP.
  • A brand new drag and drop GUI with per-module settings and keybinds.
